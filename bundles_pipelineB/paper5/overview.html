Erasing the Invisible

Overview

This competition evaluates the robustness of invisible watermarks in AI-generated images against adversarial attacks, aiming to minimize watermark detection while preserving image quality.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
