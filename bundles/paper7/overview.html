EEG Foundation Challenge

Overview

The EEG Foundation Challenge consists of two tasks: predicting behavioral performance (response time) in the Contrast Change Detection (CCD) task using EEG data and demographic traits, and predicting continuous latent psychological constructs (e.g., internalization, externalization, attention, and the p-factor) using EEG data and demographic traits.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
