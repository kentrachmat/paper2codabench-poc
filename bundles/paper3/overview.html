FAIR Universe HiggsML Uncertainty Challenge

Overview

Develop machine learning models to estimate the signal strength parameter (µ) and provide a 68.27% Confidence Interval (CI), accounting for both aleatoric and epistemic uncertainties. The task involves systematic biases introduced by six nuisance parameters to simulate real-world uncertainties.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
