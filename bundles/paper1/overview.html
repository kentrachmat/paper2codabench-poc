Airfoil Design Optimization via ML-Based Surrogate Models

Overview

Develop machine learning models to simulate computational fluid dynamics (CFD) for airfoil design, replacing computationally expensive numerical methods. The goal is to predict physical simulation outputs (e.g., velocity, pressure, lift, drag) based on input geometries and boundary conditions, while optimizing computational efficiency, accuracy, and physical consistency.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
