Concordia Cooperative Intelligence Challenge

Overview

Develop and evaluate autonomous language model agents capable of cooperative reasoning, communication, and decision-making in diverse, mixed-motive, text-mediated environments to maximize joint welfare.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
