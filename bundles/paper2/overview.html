NeurIPS 2024 LLM Privacy Challenge

Overview

A competition to identify privacy vulnerabilities in large language models (LLMs) and develop defenses to mitigate sensitive information leakage while maintaining model utility.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
