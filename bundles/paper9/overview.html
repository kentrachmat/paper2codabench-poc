Early-Stage Evaluation of Small Language Models (SLMs) for Scientific Knowledge and Reasoning

Overview

The task challenges participants to design or adapt evaluation benchmarks that better capture early-stage learning progress of Small Language Models (SLMs), particularly in scientific domains, and to differentiate between models trained on scientific knowledge-focused datasets and those trained on general web data.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
