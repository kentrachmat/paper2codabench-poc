Erasing the Invisible

Overview

The task evaluates the robustness of invisible watermarking techniques embedded in AI-generated images against adversarial attacks. Participants must design methods to remove or degrade watermarks while preserving the visual quality of the images.

Submission Format

Submit a Python file solution.py that defines a predict(input_dir, output_dir) function.

  • Read input data from input_dir/input.csv
  • Generate predictions
  • Write predictions.csv to output_dir
